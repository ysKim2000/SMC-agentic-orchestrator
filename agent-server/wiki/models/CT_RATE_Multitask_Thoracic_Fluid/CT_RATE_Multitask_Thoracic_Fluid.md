## 설명
Multi-label classifier for pleural and pericardial effusion on chest CT, trained on CT-RATE. Input: chest CT (volumetric (NIfTI)); file formats nii, nii.gz. Assesses: pleural effusion, pericardial effusion. Outputs: per-finding probabilities, Grad-CAM axial montage.
