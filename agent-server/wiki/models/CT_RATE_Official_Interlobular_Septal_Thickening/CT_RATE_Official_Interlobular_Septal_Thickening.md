## 설명
Binary classifier for interlobular septal thickening on a chest CT volume, trained on CT-RATE. Input: chest CT (volumetric (NIfTI)); file formats nii, nii.gz. Assesses: interlobular septal thickening, septal lines. Outputs: probability, binary decision, Grad-CAM axial montage.
