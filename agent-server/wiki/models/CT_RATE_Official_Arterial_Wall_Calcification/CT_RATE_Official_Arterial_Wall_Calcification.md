## 설명
Binary classifier for arterial wall calcification on a chest CT volume, trained on CT-RATE. Input: chest CT (volumetric (NIfTI)); file formats nii, nii.gz. Assesses: arterial wall calcification, aortic calcification, vascular calcification. Outputs: probability, binary decision, Grad-CAM axial montage.
