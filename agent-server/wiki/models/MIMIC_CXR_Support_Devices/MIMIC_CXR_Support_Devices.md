## 설명
Binary classifier for support devices on a chest radiograph, trained on MIMIC-CXR. Input: chest X-ray (frontal or lateral radiograph); file formats png, jpg, jpeg. Assesses: support devices, endotracheal tube, nasogastric tube, central venous catheter, pacemaker. Outputs: probability, binary decision, Grad-CAM overlay.
