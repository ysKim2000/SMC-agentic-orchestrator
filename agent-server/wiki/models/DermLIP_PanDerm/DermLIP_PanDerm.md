## 설명
Zero-shot skin-condition classifier over thirteen conditions. Input: skin clinical photograph; file formats png, jpg, jpeg. Assesses: acne, actinic keratosis, basal cell carcinoma, eczema, melanoma, nevus, psoriasis, rosacea, seborrheic keratosis, squamous cell carcinoma, tinea, urticaria. Outputs: per-condition probabilities, Grad-CAM overlay.
