## 설명
Tuberculosis-consistent abnormality classifier on a chest radiograph, three-member ensemble trained on Shenzhen. Input: chest X-ray (frontal or lateral radiograph); file formats png, jpg, jpeg. Assesses: tuberculosis-consistent abnormality, pulmonary tuberculosis. Outputs: probability, Grad-CAM overlay.
