## 설명
ECG-FM multi-label classifier for rhythm and conduction findings. Input: heart ECG (12-lead, 10 s); file formats csv. Assesses: atrial fibrillation, atrial flutter, tachycardia, bradycardia, infarction, atrioventricular block, bundle branch block. Outputs: per-finding probabilities.
