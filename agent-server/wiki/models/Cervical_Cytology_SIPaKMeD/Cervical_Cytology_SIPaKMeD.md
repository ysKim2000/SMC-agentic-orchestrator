## 설명
Cervical cytology cell classifier, trained on SIPaKMeD. Input: cervix cytology (Pap-smear cell crop); file formats png, jpg, jpeg. Assesses: dyskeratotic, koilocytotic, metaplastic, parabasal and superficial-intermediate cervical cells. Outputs: per-class probabilities.
