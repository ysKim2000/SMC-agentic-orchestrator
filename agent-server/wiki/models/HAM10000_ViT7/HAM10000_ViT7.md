## 설명
Seven-class dermoscopic skin-lesion classifier, trained on HAM10000. Input: skin dermoscopy; file formats png, jpg, jpeg. Assesses: melanoma, melanocytic nevus, basal cell carcinoma, actinic keratosis, benign keratosis, dermatofibroma, vascular lesion. Outputs: per-class probabilities, Grad-CAM overlay.
