## 설명
Binary classifier for coronary artery wall calcification on a chest CT volume, trained on CT-RATE. Input: chest CT (volumetric (NIfTI)); file formats nii, nii.gz. Assesses: coronary artery wall calcification, coronary calcium. Outputs: probability, binary decision, Grad-CAM axial montage.
