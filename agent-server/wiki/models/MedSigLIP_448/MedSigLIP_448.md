## 설명
Zero-shot dermatology classifier over eleven conditions. Input: skin clinical photograph; file formats png, jpg, jpeg. Assesses: acne, actinic keratosis, basal cell carcinoma, eczema, melanoma, nevus, psoriasis, seborrheic keratosis, tinea, urticaria, viral wart. Outputs: per-condition probabilities, Grad-CAM overlay.
