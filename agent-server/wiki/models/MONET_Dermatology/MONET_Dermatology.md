## 설명
Zero-shot dermatology concept classifier. Input: skin clinical photograph; file formats png, jpg, jpeg. Assesses: melanoma, nevus, basal cell carcinoma, squamous cell carcinoma, actinic keratosis, seborrheic keratosis, dermatofibroma. Outputs: per-concept probabilities, Grad-CAM overlay.
