## 설명
Binary classifier for peribronchial thickening on a chest CT volume, trained on CT-RATE. Input: chest CT (volumetric (NIfTI)); file formats nii, nii.gz. Assesses: peribronchial thickening, bronchial wall thickening. Outputs: probability, binary decision, Grad-CAM axial montage.
