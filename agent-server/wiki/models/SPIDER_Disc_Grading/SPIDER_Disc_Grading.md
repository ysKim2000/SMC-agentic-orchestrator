## 설명
Lumbar disc Pfirrmann grading and disc finding classifier, trained on SPIDER. Input: lumbar spine MRI (sagittal T2 disc patch); file formats png, jpg, jpeg. Assesses: disc degeneration, Pfirrmann grade, disc herniation, disc bulging, disc narrowing, Modic change. Outputs: Pfirrmann probabilities, binary disc findings, Grad-CAM overlay.
