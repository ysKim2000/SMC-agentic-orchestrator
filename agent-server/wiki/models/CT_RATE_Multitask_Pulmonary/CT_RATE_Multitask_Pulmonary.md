## 설명
Multi-label classifier for eight pulmonary findings on chest CT, trained on CT-RATE. Input: chest CT (volumetric (NIfTI)); file formats nii, nii.gz. Assesses: emphysema, atelectasis, lung nodule, lung opacity, pulmonary fibrotic sequela, mosaic attenuation pattern, interlobular septal thickening, consolidation. Outputs: per-finding probabilities, Grad-CAM axial montage.
