## 설명
Projection classifier (AP versus PA) for a chest radiograph, trained on MIMIC-CXR. Input: chest X-ray (frontal or lateral radiograph); file formats png, jpg, jpeg. Assesses: AP versus PA projection. Outputs: probability, Grad-CAM overlay.
