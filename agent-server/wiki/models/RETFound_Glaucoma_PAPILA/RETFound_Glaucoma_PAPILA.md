## 설명
Three-class glaucoma classifier built on RETFound, trained on PAPILA. Input: eye fundus photograph (color fundus); file formats png, jpg, jpeg. Assesses: glaucoma, glaucoma suspect, normal optic disc. Outputs: per-class probabilities, Grad-CAM overlay.
